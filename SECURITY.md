# Security Policy

## Reporting a vulnerability

Do **not** report security vulnerabilities through public GitHub issues, pull requests, screenshots, or social media.

Report suspected vulnerabilities privately to **support@credonomics.in**.

Include only the minimum information needed to reproduce the issue:

- affected page, feature, or commit
- impact and realistic attack scenario
- minimal reproduction steps
- browser / operating system when relevant
- sanitized logs or screenshots if useful

Do not include passwords, API keys, Supabase service-role keys, session tokens, customer data, bank/payment information, private documents, or other secrets.

## Safe testing expectations

CredFlow is currently a development project/prototype. Use synthetic or test data only.

- Do not test with real customer, friend, card, bank, or payment data.
- Do not attempt denial-of-service, destructive data modification, credential theft, or access to information that is not yours.
- Stop testing if you unexpectedly encounter private or sensitive information.
- Do not publish exploit details before CredoNomics Investment Solutions has had a reasonable opportunity to investigate and remediate the issue.
